# Rani Ketki ki Kahani (rani-ketki-ki-kahani)

Produced by the cloud project thread "University-ready book list" (queue: /mnt/project-files/notes/book-queue.md, item 1).
Claimed in docs/hec-queue.json with status `cloud_thread` so the hourly hec-book-worker does not start it.

## Source
- Urdu text: Dastan Rani Ketki aur Kunwar Ude Bhan ki, ed. Maulvi Abdul Haq, Anjuman Taraqqi-e-Urdu, Aurangabad (Deccan), 1933.
  Maulana Azad Library (AMU) copy, Digital Library of India scan: https://archive.org/details/in.ernet.dli.2015.415753 (66 pp.; text pp. 1-51 = PDF pages 10-60).
  DLI OCR (_djvu.txt) is unusable; the text was transcribed from page images (220 dpi) page by page.
- Omitted: editor's preface (dibacha), footnotes (variants and glosses), Anjuman rules page, colophon.
- Author died 1817: public domain everywhere. Editor's matter not used. us_status: not applicable (pre-1931 work; only the 1933 editorial apparatus would matter, and it is omitted).

## Chapters
1 About this edition + Introduction (new), 2-7 Insha's text split at his own section headings, 8 Glossary (new).
Urdu spelling follows the 1933 print (اوس، اون etc.). Paragraphs split more often than the print for pairing. Verse: one misra per line, one couplet per block.
